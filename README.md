# 文字式パーク

小学校6年生「文字と式」を学ぶWeb教材です。文字（xなど）が何を表すのかを見つけ、言葉を式にし、式の意味を読む。3つのコースで、文字式の考え方を段階的に身につけます。

## 公開ページ

[GitHub Pagesで開く](https://tt-sensei.github.io/mojisiki/)

## コース（各15問）

1. 式の値を求める：y = x + 5 のように、xに数を当てはめて値を計算する
2. 言葉を式にする：買い物や分け方などの場面を、文字を使った式で表す
3. 式の意味を読む：式が表している場面や関係を読み取る

## サポート

- ナビキャラ6人が、考える場面に合わせて声をかけます
- 条件を満たすとバッジがもらえます（初めての正解、連続正解、1コース15問の全問正解など）
- 進み具合は端末内（localStorage）に保存されます

## 対象

小学校6年生（算数「文字と式」）。中学校の文字式への橋渡しにもなります。

## 技術メモ

- `index.html` の単一ファイルで動作し、ビルド不要
- バッジ画像は共通素材（edu-assets）を読み込んでいます
